## Description
The dataset represents a sales transaction data set of UK-based B2C e-commerce (online retail) for one year. The data set contains 500K rows and 8 columns.

The dataset includes:
- Unique transaction numbers, where the letter “C” in the code indicates a cancellation.
- Date when each transaction was generated.
- Unique product numbers to identify a specific product.
- Products/items names.
- Price of each product per unit in pound sterling (£).
- Quantity each product per transaction. Negative values related to cancelled transactions.
- Unique customer numbers.
- Names of countries where the customer resides.

## Table Schema

### `UK_online_retail_db`

Columns:

- TransactionNo
- Date
- ProductNo
- Product
- Price
- Quantity
- CustomerNo
- Country

## Purpose in This Project

The dataset is used to understand how can a UK-based online retailer improve revenue growth by understanding customer retention, repeat purchasing, product performance, and country-level demand.
